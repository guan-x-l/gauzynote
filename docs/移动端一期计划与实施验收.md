# 移动端一期：计划、实施与验收

- 制定日期：2026-09-14
- 所属模块：`gauzynote-web`
- 当前状态：移动端前端代码已实施；真实后端联调、PC 回归及真机验收仍待执行。勾选项仅表示代码或本地自动化已完成，完整验收以第六节记录为准。

## 一、目标与范围

在同一个 `gauzynote-web` 工程中新增独立的移动端布局、页面和 `/m` 路由，复用现有后端接口、认证、主题、国际化及 Markdown 渲染能力。移动端支持完整登录流程、只读目录浏览、已有笔记阅读与编辑，以及精简的个人设置。

移动端页面不嵌入桌面布局，不依赖桌面多标签页状态，也不采用桌面端通过路由元信息加载动态组件的方式。首页底部菜单可以使用动态组件切换面板，点击笔记则通过普通路由进入独立页面。

### 1.1 一期功能

| 模块 | 包含功能 | 边界 |
| --- | --- | --- |
| 登录 | 账号密码登录、使用已有 Passkey 登录、必要的初始密码修改、登录失效处理、登录后回跳 | 保持现有认证规则，不新增认证方式 |
| 目录 | 浏览已有目录层级、逐级进入、打开已有笔记 | 只读浏览，不提供目录修改操作 |
| 笔记 | 阅读、编辑已有标题和 Markdown 正文、简化工具栏、阅读与编辑切换、手动及自动保存 | 不提供搜索、新建或删除 |
| 我的 | 账号信息展示、主题切换、语言切换、退出登录 | 账号信息只读；不提供常规修改密码、回收站及其他设置入口 |

必要的初始密码修改属于登录后的账号初始化流程，不属于“我的”中的常规设置。

### 1.2 明确不做

- 笔记名称搜索、全文搜索、新建笔记、删除笔记。
- 新建目录、重命名目录、移动笔记、删除目录。
- 文件管理、上传、任务、回收站、用户管理、字典管理。
- 桌面多标签页、拖拽分栏、拖拽排序、实时预览编辑。
- 离线同步、多人协同编辑、额外后端能力建设。

已有笔记中的图片和附件链接保持现有渲染与访问语义，但不新增附件管理页面或上传入口。目录列表仅展示目录和笔记，隐藏非笔记文件；只含附件的目录显示为空目录。Passkey 仅复用已有凭证登录，不新增凭证注册、重命名或撤销页面。

## 二、页面与交互设计

### 2.1 路由

现有应用部署前缀为 `/gauzynote/`，以下为 Vue Router 内部路径：

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/m/login` | 移动登录页 | 独立页面，处理登录回跳 |
| `/m` | 移动首页 | 默认展示目录，底部菜单为“目录 / 我的” |
| `/m/note/:id` | 移动笔记页 | 普通路由页面，按笔记 ID 加载内容 |

实际首页地址为 `/gauzynote/m`。路由组件允许按需导入，但不使用桌面端的 `meta.dynamicComponent`、动态组件命名和标签页缓存机制。

### 2.2 页面行为

- 首页底部菜单只包含“目录”和“我的”，可用局部动态组件切换。
- 目录采用逐级进入方式，提供返回上级操作，保留当前目录位置。
- 点击笔记跳转至独立笔记页，笔记页不显示首页底部菜单。
- 笔记默认进入阅读模式；右上角可在阅读与编辑间切换，编辑时显示源码编辑区域。
- 笔记页提供顶部返回入口；从目录进入时，返回后恢复目录位置和滚动位置。
- 直接访问笔记链接且无有效目录来源时，页面返回按钮回到移动首页。
- 需要区分目录层级返回、笔记返回和浏览器历史返回，防止返回循环。
- 简化工具栏提供标题、加粗、列表、待办、链接和代码等常用 Markdown 插入操作，不包含上传。

### 2.3 入口策略与待确认扩展

- 一期保证 `/gauzynote/m` 和移动笔记链接可直接访问，不要求设备识别才能使用。
- PC 原有路径保持原有行为，移动路由在任何设备上均可显式访问。
- 自动识别手机、PC / 移动版切换按钮、偏好记忆及平板分流策略尚未确认，不纳入当前实施和验收范围。
- 横竖屏变化仅调整移动页面布局，不触发跳转。

## 三、技术实施原则

### 3.1 目录与复用边界

建议在 `src/mobile/` 下集中放置移动端首页、页面、组件及必要的局部状态，新增独立的移动路由定义。

- 复用现有 `src/api/`、认证请求、主题、国际化和 Markdown 渲染能力。
- 移动端业务页面与样式独立，优先局部样式，避免影响 PC。
- 不直接搬用依赖 `tabsStore` 的桌面笔记页、文件页或编辑器外壳。
- 编辑器可复用 CodeMirror 底层能力，采用精简配置，不复制整套桌面插件。
- 仅提取实际需要共享的逻辑，不为一期进行大规模状态管理或组件重构。
- 保持接口参数和数据语义，精简界面不能清空未展示的业务字段。

### 3.2 认证流程

- 统一检查移动登录入口、路由鉴权、请求未授权处理和退出登录跳转。
- 未登录访问笔记时保存目标路径，完成登录及必要初始化后回到该笔记。
- 校验回跳目标为应用内有效路径，避免外部跳转及登录循环。
- Passkey 保持现有流程，处理取消、失败和环境不支持；密码登录仍可使用。
- 初始密码修改沿用现有后端规则，核对触发条件和完成后的跳转行为。
- 退出时清理移动端用户数据和编辑状态，避免后续账号看到上一账号的内容。
- 认证失效优先于普通未保存离开拦截：停止自动保存，在当前页面内存中暂存未提交内容并提示复制后重新登录；用户继续后才跳转登录页。禁止失效后继续请求受保护数据，不自动向重新登录的账号提交暂存内容。重新登录或退出前清理暂存内容；刷新及强制关闭不保证恢复。

### 3.3 笔记加载与保存

- 以路由笔记 ID 为数据来源，不读取桌面当前标签页。
- 标题更新和正文保存沿用各自接口；分别处理成功、失败，不能因其中一个成功就把全部修改标记为已保存。
- 提供“未保存、保存中、已保存、保存失败”状态及失败重试入口。
- 自动保存采用编辑后延迟提交，同时保留手动保存。
- 跟踪提交时的内容快照：请求期间继续输入时，旧请求成功不能清除新内容的未保存状态。
- 防止加载响应串到另一篇笔记，避免保存请求乱序覆盖。
- 阅读与编辑切换只改变展示形式，不丢弃编辑内容。
- 应用内返回遇到未保存内容时，等待保存成功，或允许明确选择继续编辑、放弃修改；失败时保留当前内容。
- 不依赖页面卸载时发起请求来保证保存成功，不承诺浏览器被强制关闭后恢复未提交内容。
- 本地草稿恢复不列为一期默认功能；如后续加入，须按账号和笔记隔离。
- 跨设备同时编辑的冲突保护需核实后端能力，一期不承诺合并或协同编辑。
